# Sales CRM — Οδηγίες Εγκατάστασης

## Απαιτήσεις
- PHP 8.0+
- MySQL 5.7+ ή MariaDB 10.3+
- Apache με mod_rewrite (ή Nginx)
- Hosting με cPanel / Plesk (ή οποιοδήποτε shared hosting)

---

## Βήμα 1 — Ανεβάστε τα αρχεία

Ανεβάστε **όλα** τα αρχεία του φακέλου `sales-crm/` στον web server σας μέσω FTP ή cPanel File Manager.

Συνιστάται να τα βάλετε σε:
- `public_html/crm/` → το CRM θα είναι στο `https://yoursite.com/crm/`
- ή `public_html/` αν θέλετε root

---

## Βήμα 2 — Δημιουργήστε τη βάση δεδομένων

1. Ανοίξτε το **phpMyAdmin** από το cPanel σας
2. Δημιουργήστε νέα βάση δεδομένων με όνομα `sales_crm`
3. Επιλέξτε τη βάση και κάντε κλικ στο **Import**
4. Ανεβάστε το αρχείο `install.sql`
5. Κάντε κλικ **Go** / **Εκτέλεση**

---

## Βήμα 3 — Επεξεργαστείτε το config.php

Ανοίξτε το αρχείο `config.php` και αλλάξτε:

```php
define('DB_HOST', 'localhost');       // συνήθως localhost
define('DB_NAME', 'sales_crm');       // όνομα βάσης που δημιουργήσατε
define('DB_USER', 'your_db_user');    // χρήστης βάσης από cPanel
define('DB_PASS', 'your_db_pass');    // κωδικός βάσης
```

Αν το CRM δεν είναι στο root αλλά σε υποφάκελο (π.χ. `/crm/`):
```php
define('UPLOAD_URL', '/crm/uploads/');
```

---

## Βήμα 4 — Δικαιώματα φακέλου uploads

Δώστε στον φάκελο `uploads/` δικαίωμα **755** (ή 775 αν χρειαστεί):

Μέσω cPanel File Manager:
- Δεξί κλικ στο `uploads/` → Permissions → 755

Μέσω FTP: `chmod 755 uploads/`

---

## Βήμα 5 — Σύνδεση

Ανοίξτε το CRM στο browser σας και συνδεθείτε:

| | |
|---|---|
| **URL** | `https://yoursite.com/crm/` |
| **Username** | `admin` |
| **Password** | `password` |

⚠️ **Αλλάξτε αμέσως τον κωδικό** από Ρυθμίσεις → Αλλαγή Κωδικού Admin

---

## Δομή αρχείων

```
sales-crm/
├── index.php          ← Σελίδα login
├── dashboard.php      ← Admin panel
├── partner.php        ← Partner portal
├── api.php            ← API (AJAX)
├── save_draft.php     ← Session handler για νέα αίτηση
├── logout.php         ← Αποσύνδεση
├── config.php         ← Ρυθμίσεις βάσης (επεξεργαστείτε αυτό!)
├── layout.php         ← Κοινό HTML/CSS
├── install.sql        ← Βάση δεδομένων (τρέξτε μία φορά)
├── .htaccess          ← Apache ασφάλεια
└── uploads/           ← Φάκελος δικαιολογητικών
    └── .htaccess      ← Μπλοκάρει εκτέλεση PHP στα uploads
```

---

## Δημιουργία Partner (Εξωτερικός Πωλητής)

1. Συνδεθείτε ως Admin
2. Μεταβείτε στη σελίδα **Συνεργάτες**
3. Κάντε κλικ **+ Νέος Συνεργάτης**
4. Συμπληρώστε τα στοιχεία και δώστε username + κωδικό
5. Ο partner μπορεί να συνδεθεί στο ίδιο URL

---

## Ρυθμίσεις Admin

Από τη σελίδα **Ρυθμίσεις** μπορείτε να:
- Προσθέσετε/αφαιρέσετε **Κατηγορίες** (Τηλεφωνία, Ρεύμα κλπ.)
- Προσθέσετε **Παρόχους** ανά κατηγορία
- Προσθέσετε **Προϊόντα** ανά πάροχο
- Διαχειριστείτε **Στάτους** αιτήσεων
- Προσθέσετε εταιρείες/προγράμματα στο **InfoPortal**

---

## Δικαιολογητικά

Όλα τα ανεβασμένα αρχεία αποθηκεύονται στον φάκελο `uploads/` του server.

Ως Admin, τα βλέπετε ως φωτογραφίες/PDFs μέσα στην προβολή κάθε αίτησης (κλικ στο κουμπί **Προβολή**).

---

## Αντιμετώπιση προβλημάτων

**"Σφάλμα σύνδεσης με τη βάση δεδομένων"**
→ Ελέγξτε τα στοιχεία στο `config.php`

**"403 Forbidden" στο uploads/**
→ Ελέγξτε τα δικαιώματα φακέλου (755)

**Τα αρχεία δεν ανεβαίνουν**
→ Ελέγξτε ότι ο φάκελος `uploads/` είναι writable (chmod 755 ή 775)

**Το .htaccess δεν λειτουργεί**
→ Βεβαιωθείτε ότι το Apache έχει ενεργοποιημένο το `AllowOverride All` ή επικοινωνήστε με τον hosting provider
